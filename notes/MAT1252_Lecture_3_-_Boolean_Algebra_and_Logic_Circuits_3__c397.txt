One major advantage of using a notation with symbols "•"
and "+" is that many of the laws of logic look like the familiar
laws of ordinary algebra, and that makes algebraic
manipulation so much easier.

Order of operations:

• "complement (')" takes precedence over "multiplication (•)“

• "multiplication (•)" takes precedence over "addition (+)"

unless indicated otherwise by means of brackets.

Boolean Algebra

Example: Evaluate the Boolean expression x + y'• z, in
the case where x = 1, y = 0, z = 0.

Solution: Based on order of operations, first find y' and
then y'•z, and finally x + y'•z.

In other words we first perform the "complement (')", then
the "multiplication (•)" and finally the "addition (+)".

So x + y'• z = 1 + ((0') • 0) = 1 + (1 • 0) = 1 + 0 = 1.

Logic gates

A logic gate is an electronic device which implements
Boolean operations.

It has one or more inputs each of which will accept a "low“
voltage (input = 0) or a "high" voltage (input = 1).

28

Logic gates

AND gate

An AND gate has two or more inputs, and its output is the 
product of the inputs.

The output of an AND is 1 if all the inputs are 1; otherwise
the output is 0.

29

2inAND3inAND5inANDLogic gates

OR gate

An OR gate has two or more inputs, and its output is the 
Boolean sum of the inputs.

The output of an OR is 0 if all the inputs are 0; otherwise 
the output is 1.

30

2inOR3inOR5inORLogic gates

NOT gate

A NOT gate (also called an inverter) has one input and one 
output. 

The output of a NOT is the complement (opposite) of the 
input.  

In other words, an input of 1 gives output of 0 and vice versa.

Fundamental products

In order to find a Boolean expression corresponding to a given truth 
table, we need the concept of fundamental product. In a fundamental 
product, each variable must be present, with or without a complement.

For just two variables x and y, there are four fundamental products.

They are:

xy,   xy',   x'y and  x'y'

For three variables x, y and z, there are eight fundamental products:

xyz,   xyz',   xy'z,   xy'z',   x'yz,   x'yz',   x'y'z,   and  x'y'z'

In general, if there are n variables, there will be

Using the laws: a note

The commutativity law says:

(i)   in any product, the order of multiplication is unimportant.

e.g. xy'z = y'xz = zy'x = … etc.

(ii)  in any sum, the order of addition is unimportant.

e.g. x' + y' + z = y' + x' + z = z + y' + x' =  … etc.

The distributive law says:

x(y + z) = xy + xz

which can be used to remove brackets

It can also be extended to cases such as:

(w + x)(y + z) = wy + wz + xy + xz

and

x(w + y + z) = xw + xy + xz.

Expanding a SOP into a complete sum of 
products

Sometimes it is desirable to expand a sum of products into
a complete sum of products.

In a complete sum of products each term must be a 
fundamental product; that is, in each term every variable 
must be present, with or without a complement.

If any term of a sum of products has a variable missing, we
multiply the term by 1 in the form (var + var').

Since the sum (var + var') = 1, we are multiplying by 1,
which does not alter the value of the original expression.
